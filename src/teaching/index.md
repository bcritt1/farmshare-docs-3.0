Instructors can use FarmShare for a course without asking us for anything, since
every student with a full-service SUNet ID can already log in. What we add is
shared space, software and capacity for the class, and each of those needs a
request from you.

## What We Can Set Up for a Course

| What | What it's for | Where to read more |
|---|---|---|
| Course directory and workgroups | Shared course files, with staff who can edit them and students who can read them | [Set Up a Course](set-up-a-course.md) |
| Class scratch directory | Large data sets that the whole class reads | [Set Up a Course](set-up-a-course.md) |
| Drop-box folders | Students handing in work through the course directory | [Add Students and TAs](add-students-and-tas.md) |
| Course software | Programs the class needs, installed as modules or in the course directory | [Request Course Software or Reserved Nodes](course-software-and-reservations.md) |
| Shared containers | One prepared software environment for everyone in the class | [Request Course Software or Reserved Nodes](course-software-and-reservations.md) |
| Reserved nodes or GPUs | An assignment or competition that needs guaranteed capacity at a set time | [Request Course Software or Reserved Nodes](course-software-and-reservations.md) |

We can also tell you what to expect when the whole class works at once, for
example if everyone opens a desktop in the same week. Ask us before you plan an
assignment around it.

SRC also has teaching materials on using FarmShare that you can import into your
Canvas course. See [Teaching Materials](materials.md).

## Who Asks

Requests for a course usually come from the instructor of record. If a TA asks,
we'll check with the instructor and make them the owner. Your TAs can help with
the details, and once the course is set up they can manage the student list
themselves. See [Set Up a Course](set-up-a-course.md).

## When to Ask

!!! review "Needs Review"
    Is there a typical lead time for a course setup, software or a reservation
    that we can give instructors?

Ask as early as you can, before the quarter starts. A course directory is quick
to set up. Software, shared containers and reservations take longer, because we
install and test them first. The first weeks of each quarter are also our
busiest time for support.

## Timeline

1. Before the quarter starts, email {{ facts.support_email }} with everything
   the course needs: the directory, scratch space, software and any
   reservations. See [Set Up a Course](set-up-a-course.md) for what to include.
2. Once we've set it up, add your TAs to the staff workgroup and have them add
   students. See [Add Students and TAs](add-students-and-tas.md).
3. Test the course software and your assignments on FarmShare yourself, the way
   students will run them.
4. Before the first assignment, go through [Get Ready for Class
   Day](class-day.md) with your students.

## Where to Get Help

!!! review "Needs Review"
    Does adding "urgent" to the subject change how a request is handled?

Email {{ facts.support_email }} with "FarmShare" in the subject. We answer
during business hours. If something breaks close to a class, add "urgent" to the
subject. See [Get Help](../fix/get-help.md).
