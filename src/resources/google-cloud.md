Google Cloud Platform (GCP) is a commercial cloud service you can use for
computing when FarmShare isn't the right fit. There are a few ways to get it at
Stanford. None of them is a Stanford Research Computing service, except Nero,
which is described below.

## When Google Cloud Is Useful

Cloud computing lets you pay for exactly the machines you need, when you need
them, including GPU types and memory sizes FarmShare doesn't have. You're billed
for what you use, so it suits work that's short, irregular, or needs something
specific. For work that fits within FarmShare's limits, FarmShare is free.

## Stanford GCP Projects

University IT runs Stanford's Google Cloud accounts. A Stanford GCP project
comes under Stanford's agreements with Google, and you log in with your SUNet
ID. It's billed to a Stanford PTA, so you need approval from someone who can
approve charges to that PTA before you request a project.

See University IT's [Guide to Stanford GCP
Setup](https://uit.stanford.edu/service/cloudacctmgmt/gcp) for how to request a
project. Questions go to University IT, not to us.

## Google Cloud for Courses

Google offers education credits that instructors can apply for to teach a course
with Google Cloud. The credits go into a billing account for the course. See
[Google Cloud for Education](https://cloud.google.com/edu/faculty) for
eligibility and how to apply.

## Personal Google Cloud Accounts

You can also sign up for Google Cloud yourself with a personal account and pay
Google directly. A personal account isn't a Stanford project, so it isn't
covered by Stanford's agreements with Google. Don't use one for Stanford data
unless you've checked that it's allowed for that data.

## High-Risk Data

FarmShare can't be used for high-risk data. Stanford's guidance is that
high-risk data on Google Cloud has to be managed by an authorized group, such as
Stanford Research Computing. [Nero](nero.md) is SRC's Google Cloud environment
for high-risk data, and it's the place to start if your work involves it.
