Nero is a cloud computing environment and big data platform for high-risk data,
built on Google Cloud. Stanford Research Computing runs it, like FarmShare, but
it's a separate system with its own accounts and documentation.

## When to Use Nero Instead

FarmShare can't be used for high-risk data, such as protected health information
or personally identifiable information. If your work involves high-risk data and
fits a cloud environment, use Nero. For an on-premises option, see
[Carina](carina.md).

## Getting Access

See the [Nero documentation](https://nero-docs.stanford.edu/) for how to request
access.
